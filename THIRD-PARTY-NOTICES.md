- The dashboard has no JavaScript dependencies and loads nothing from a CDN.

## Packages installed in the Docker image

These come from the Debian and Python base images (`python:3.12-slim`) and are installed by `backend/Dockerfile`. Their license texts are inside the image under `/usr/share/doc/<package>/copyright`.

| Component | What it is used for | License |
|---|---|---|
| Python 3.12 | the runtime | PSF License |
| ffmpeg (provides `ffprobe`) | reading audio and subtitle streams of a file (optional deep scan) | LGPL-2.1+ or GPL-2+, depending on the build (the Debian package; run as a separate program, not linked into Tidyfin) |
| fonts-dejavu-core (DejaVu Sans) | drawing badge text on posters | Bitstream Vera Fonts license, with public-domain parts |
| Debian GNU/Linux | the base system | various, see the base image |

The source code of the Debian packages is available from Debian (https://www.debian.org/distrib/packages and `apt source <package>`).
